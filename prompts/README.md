# Папка с промптами и ТЗ для проекта

Сюда можно сохранять любые `.txt` или `.md` файлы с подробными техническими заданиями, описанием фич или промптами.

### Как использовать в диалоге:
Просто напишите:
- *"Сделай задачу из prompts/shop_ui.txt"*
- *"Прочитай новый файл в папке prompts и реализуй его"*

Ассистент автоматически прочитает файл, изучит требования и реализует логику в Roblox Studio.
